Know the tradeoffs

Questions a buyer should ask

Is this enterprise certified?

No. RivetFlow is an engineering portfolio platform, not an audited enterprise SaaS. Deployment suitability and controls are assessed before any agreement.

Do I get the source code?

RivetFlow's underlying open-source code is available under MIT. The paid engagement covers specification, adaptation, integration and deployment—not an exclusive software license.

Is AI execution included?

Remote AI is disabled by default in the public project. Any AI-enabled use requires explicit scope, cost controls and an agreed provider configuration.

What if our process is a bad fit?

We will say so at the fit review. Complex integrations, sensitive data, mandatory enterprise identity systems and regulated workloads may require a different solution.
